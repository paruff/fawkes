Thank you for your interest in contributing to Fawkes! The full contributor guide lives at **[docs/contributing.md](docs/contributing.md)** — start there.

Quick links:

- [Development workflow](docs/contributing.md#development-workflow) (trunk-based, short-lived branches)
- [Code quality gates](docs/contributing.md#3-code-quality-standards) (`make lint` before every commit)
- [PR standard](docs/PR_STANDARD.md) (Conventional Commits, 400-line limit, required PR body)
- [Tests](tests/README.md) (`make test-all`; integration tests need a live cluster)
